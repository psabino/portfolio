Paw Puzzles

A mobile blast game with cute dogs 🐾

Overview

Paw Puzzles is a dog themed blast game with a puzzle meta. I had the opportunity to work at some amazing new features, such as Character's Collection, Stories, Shop, a few micro-interactions and general improvements for the soft launch.

Role

UI Designer

Kiloo Games

Aarhus - Denmark (On-site)

Apr - Jun 2023

The Problem

This project was already in development when I joined Kiloo Games, and the visual identity was already defined. We had a very short time window until the soft launch and the game was still missing some key features to the core loop. This would impact directly the user experience, leaving the players without a sense of progression across the game.

Benchmark & Research

I used Game Refinery to filter games by the same genre and user base, gathering references for two new features aligned with our project's GDD:

  • Character Collection: In this area, players can see the characters they already own, with a small profile containing the lore and extra info. They can also check the characters that will be unlocked in the future.
  • Stories: Paw Puzzles' meta is all around solving puzzles to reveal a story. We needed an area where players could rewatch them, but also have a small preview of what is coming in the next chapters.
